# Gaurav Khanduri Portfolio

A creative static portfolio website for an aspiring web developer with customer operations, airline feedback, e-commerce support, and data reporting experience.

## Files

- `index.html` - page structure and portfolio content
- `styles.css` - responsive visual design
- `script.js` - mobile navigation behavior
- `projects/` - three mini portfolio projects
- `assets/Gaurav-Khanduri-Resume.pdf` - downloadable resume
- `assets/gaurav-profile.jpeg` - portfolio profile image

## How to open

Open `index.html` in a browser.
