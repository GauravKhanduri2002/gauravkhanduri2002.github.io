# Gaurav Khanduri Portfolio

A creative static portfolio website for an aspiring web developer with customer operations, airline feedback, e-commerce support, and data reporting experience.

## Files

- `index.html` - page structure and portfolio content
- `styles.css` - responsive visual design
- `script.js` - mobile navigation behavior
- `projects/` - three mini portfolio projects
- `assets/Gaurav-Khanduri-Resume.pdf` - downloadable resume
- `assets/Gaurav-Khanduri-Frontend-Developer-Resume.html` - frontend-focused printable resume
- `assets/Gaurav-Khanduri-Frontend-Developer-Resume.md` - ATS-friendly resume text
- `assets/gaurav-profile.jpeg` - portfolio profile image
- `assets/favicon.svg` - browser tab icon

## How to open

Open `index.html` in a browser.

## Current interactive features

- Project apps save demo data in the browser with `localStorage`.
- Project apps include toast notifications, empty states, filters, and live UI updates.
- Contact form opens a prepared email draft through the user's mail app.
